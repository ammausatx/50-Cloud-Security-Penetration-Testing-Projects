# 50 Cloud Security & Penetration Testing Projects

A practical multi-cloud portfolio covering **AWS, Microsoft Azure, and Google Cloud Platform (GCP)**, organized into 15 beginner, 20 intermediate, and 15 advanced projects.

> **Authorization and safety:** Use dedicated lab accounts and explicitly authorized environments only. Prefer read-only assessment and provider-native policy simulation. Do not extract credentials, access third-party tenants, or make production changes without approval. Screenshots are simulated training illustrations, not live assessment evidence.

## Project deliverables
Each project includes objective, cloud scope and rules of engagement, prerequisites, assessment workflow, example commands/tool guidance, expected results, risk analysis, remediation, validation, evidence/reporting guidance, framework references, and three simulated training illustrations.

## Evidence and safe testing
Use dedicated sandbox accounts, MFA, least-privilege identities, short-lived credentials, budgets, and explicit scope. Redact account/tenant/project IDs, resource names, tokens, private keys, email addresses, and customer data. Do not run exploitation, credential extraction, disruptive tests, or unauthorized cross-tenant activity.
